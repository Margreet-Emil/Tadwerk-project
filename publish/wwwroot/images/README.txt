TADWEERK - PHOTOS
=================
Put your real photos in this folder using EXACTLY these names (jpg). Until a file exists, the page shows a green placeholder icon instead.

  hero.jpg         big photo in the home page hero (recycling / sorting waste)
  plastic.jpg      plastic bottles
  paper.jpg        paper / cardboard
  metals.jpg       metal cans / scrap      (name = the waste type name in lowercase)
  glass.jpg        glass bottles
  electronics.jpg  e-waste
  about.jpg        photo for the About section (people sorting / collecting)

  reviewers/r1.jpg ... r6.jpg   optional face photos for the review cards
                                (only use photos of people who agreed to appear)

Tip: if you add a new waste type in the admin panel, its photo name is the type name in lowercase letters only (e.g. "Batteries" -> batteries.jpg).

Where to get free photos you may use: unsplash.com, pexels.com, pixabay.com. Check each photo's licence.
Recommended size: about 1600 x 1000 px, under 400 KB each.


NOTE - built-in fallback photos
-------------------------------
If a local file is missing, the site tries a free photo from Wikimedia Commons for: hero, plastic, paper, metals and about.
(glass and electronics have no fallback yet - add glass.jpg and electronics.jpg yourself.)
Your own file in this folder always wins over the fallback. Commons photos need an internet connection and keep their original authors' credit (shown at the bottom of the page).
